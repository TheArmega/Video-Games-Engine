\doxysubsection{Detailed Description}
Manages a collection of \doxylink{classCircle}{Circle} objects and their SFML shapes. 

This class allows adding, deleting, and managing multiple \doxylink{classCircle}{Circle} objects in a container, represented by SFML Circle\+Shape objects.
