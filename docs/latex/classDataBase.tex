\doxysubsection{Detailed Description}
Handles SQLite database operations for \doxylink{classCircle}{Circle} objects. 

This class allows creating a database, creating tables, inserting, deleting, and retrieving \doxylink{classCircle}{Circle} objects, using SQLite3.
